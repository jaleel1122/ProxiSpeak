# ProxiSpeak

ProxiSpeak is a 2D virtual workspace featuring proximity-based communication, designed to make remote collaboration feel more natural. Users move around a shared virtual workspace as avatars, with communication between users depending dynamically on their proximity to each other.

---

## The Problem & Core Idea

Remote collaboration often feels rigid, isolated, and reliant on scheduled meetings. Traditional conferencing platforms lack the spontaneous interactions, casual desk conversations, and spatial awareness found in physical offices.

**ProxiSpeak** introduces spatial presence to remote collaboration:
- Users interact as avatars inside a continuous 2D environment.
- Conversations occur organically based on physical proximity, bringing natural hallway chats and spontaneous team collaboration into a digital workspace.

---

## Key Features

- **2D Virtual Workspace**: A shared spatial map designed for remote teams to work and gather together.
- **Player/Avatar Movement**: Intuitive movement controls allowing users to navigate around the workspace.
- **Real-Time Multiplayer Interaction**: Live presence and synchronized movement across connected users.
- **Proximity-Based Voice Communication**: Spatial audio interaction where voice communication activates and adjusts based on user proximity.
- **Collaborative Workspace Experience**: An informal, presence-driven environment supporting natural team discussions and spontaneous collaboration.

---

## How It Works

1. **Join the Workspace**: Users enter the shared 2D environment represented as avatars.
2. **Move Freely**: Navigate the workspace using avatar movement controls.
3. **Engage by Proximity**: Approach teammates to initiate proximity-based voice communication naturally.
4. **Disengage Naturally**: Move away from others to conclude conversations, eliminating the need to start or end formal calls.
